# Архитектурная спецификация Puuk Web Client (`app/web`)

Документ фиксирует согласованные архитектурные решения, стек технологий, слои приложения и скоуп версий для веб-клиента сервиса **puuk**.

---

## 1. Стек технологий и ключевые решения

| Компонент | Выбранное решение | Обоснование |
|---|---|---|
| **Платформа** | `Vite + React 19 + TypeScript (Strict)` | Чистый SPA. Аудиопоток никогда не прерывается перезагрузками. Строгая типизация моделей данных. Быстрая сборка. |
| **Аудио-ядро** | `Web Audio API (AudioContext + HTMLAudioElement)` | Точный тайминг до миллисекунды для караоке (LRC), возможность в будущем подключить эквалайзер и визуализатор. |
| **Стейт-менеджмент** | `Zustand` + `TanStack Query (React Query v5)` | `Zustand` управляет состоянием плеера и очереди без лишних ре-рендеров. `TanStack Query` кэширует данные бэкенда, списки треков и управляет оптимистичными обновлениями. |
| **Анимации** | `Framer Motion (Motion)` | Физика пружин, плавный разворот полноэкранного плеера, жесты, аналог Reanimated из iOS. |
| **Стилизация** | `CSS Modules` + `CSS Custom Properties (Variables)` | Изоляция стилей каждого компонента. Динамическая смена акцентного цвета темы (`--accent-color`, `--bg-glow`) под цвет обложки играющего трека. |
| **Расположение** | `app/web/` | Автономный проект в репозитории, не завязан на мобильные абстракции React Native. |

---

## 2. Архитектура слоев (Decoupled Layer Architecture)

Бизнес-логика и аудио-движок **полностью изолированы от React**. Это обеспечивает простоту понимания кода, отличный дебаг и возможность в будущем переписать логику на WebAssembly / C++ / Rust без переделки UI.

```
┌──────────────────────────────────────────────────────────┐
│  Слой 4: UI & Компоненты (React + CSS Modules)            │ ← Только верстка, кнопки, хоткеи
├──────────────────────────────────────────────────────────┤
│  Слой 3: Стейт-машина плеера (Zustand Store)             │ ← Очередь, история, режимы (Wave/Playlist)
├──────────────────────────────────────────────────────────┤
│  Слой 2: Audio Engine (Чистый TypeScript, Zero React)     │ ← Класс управления звуком, буфером, таймингом
├──────────────────────────────────────────────────────────┤
│  Слой 1: API & DTOs (Чистый TypeScript)                  │ ← Клиент FastAPI, строгие интерфейсы моделей
└──────────────────────────────────────────────────────────┘
```

## 3. Компоновка интерфейса (Desktop-First Layout)

* **Сетка из 3 колонок:**
  1. **Левая колонка (Sidebar):** Логотип `puuk`, ссылки навигации (Главная, Поиск, Моя волна), список плейлистов пользователя.
  2. **Центральная область (Main Stage):** Скроллируемая лента треков, карточки альбомов, сетки плейлистов, результаты поиска.
  3. **Правая колонка (Collapsible Panel):** Выдвижная панель с табами: *Очередь воспроизведения* и *Текст песни (LRC)*.
* **Нижняя панель (Sticky Player Bar):**
  * Слева: обложка трека (клик открывает Fullscreen), название, исполнитель, кнопка «лайк».
  * Центр: кнопки Shuffle, Prev, Play/Pause, Next, Repeat + полоса прогресса с текущим временем.
  * Справа: кнопка вызова текста песни, кнопка очереди, ползунок громкости, кнопка Mute.
* **Полноэкранный плеер (FullPlayerModal):**
  * Разворачивается плавно через Framer Motion поверх экрана.
  * Фон динамически окрашивается в градиент доминантного цвета обложки текущего трека.
  * Большой режим караоке-текста с автоскроллом.

## 4. Горячие клавиши (Desktop Hotkeys)

* `Space` — Воспроизведение / Пауза.
* `←` / `→` — Перемотка на 5 секунд назад / вперед.
* `Shift` + `←` / `Shift` + `→` — Предыдущий / следующий трек.
* `↑` / `↓` — Увеличение / уменьшение громкости на 5%.
* `M` — Включить / выключить звук (Mute toggle).
* `L` — Открыть / скрыть панель текстов песен (Lyrics).
* `/` — Быстрый переход и фокус в строку поиска.
* `Esc` — Закрыть полноэкранный плеер или модальное окно.

## 5. Поведение плеера и текстов (Audio & Playback Rules)

1. **Тексты песен (LRC Karaoke):**
   * Парсятся на лету из тега `lyrics` трека.
   * Активная строка подсвечивается синхронно с текущей миллисекундой `AudioContext`.
   * Контейнер плавно скроллится так, чтобы текущая строка оставалась по центру.
   * **Клик по любой строке текста** перематывает трек ровно на таймкод этой строки.
2. **Окончание очереди:**
   * Когда заканчивается текущий плейлист или очередь — **плеер останавливается**.
   * Автоматический бесконечный режим «Моя Волна» через Qdrant включается **только** тогда, когда пользователь сам нажал кнопку «Запустить Волну».
3. **Подключение к бэкенду:**
   * Адрес сервера задается через `.env` переменную `VITE_API_URL` (с фоллбэком на относительный URL `/api` через Vite proxy для локальной разработки).
   * Авторизация поддерживает вход по логину/паролю и по верификационному коду из Telegram-бота. JWT токен сохраняется в `localStorage`.
