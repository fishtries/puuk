## Общий прогон: итог и особенности запуска

Проверено 601 различных backend-тестов; тяжёлый
`test_qdrant_vector_exact_backward_compatibility.py` намеренно исключён (ML-анализ
по правилам проекта выполняется локально).

Финальный общий прогон дал 596 passed и 5 ошибок запуска дочерних процессов.
Причина — pytest вызывался через stdin, multiprocessing spawn пытался открыть
несуществующий `<stdin>`. После переноса runner в обычный файл с main guard весь
`test_multi_artist_merge_race.py` прошёл: 9 passed за 10,10 с., включая все пять
упавших тестов. Четыре из этих девяти уже прошли в общем прогоне, поэтому
уникальных успешных проверок 596 + 5 = 601. Общий прогон целиком после исправления
runner повторно не запускался. Ошибок тестируемого кода не осталось.

Первый неполный прогон также обнаружил недокомплект стенда (.gitignore, аудиофайл
для Range-тестов, библиотеки aiogram). Эти недостающие тестовые ресурсы добавлены
в release-каталог; соответствующие проверки затем прошли. Модели/рабочая музыкальная
библиотека в тестовые пути не подключались.
