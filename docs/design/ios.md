## Компоненты и стили

Используются React Native, Expo, Reanimated и Gesture Handler. Версии проверять в `package.json`. CSS Modules, DOM, вебовый AudioEngine и Framer Motion к этому клиенту не относятся.

Стили полного плеера вынесены в StyleSheet, но общего набора дизайн-токенов, эквивалентного вебовому `variables.css`, этот документ не объявляет. Перед добавлением значения проверить соседние компоненты и настройки. Динамические и анимированные стили допустимы.

UI использует существующие обработчики управления воспроизведением. Декоративная анимация не должна создавать второй источник состояния аудио или задерживать команду. Учитывать safe areas, клавиатуру, масштабирование текста и доступные роли/названия элементов.

## Движение

Полный плеер раскрывается и закрывается через `withTiming`; возврат после незавершённого свайпа использует `withSpring`. Press feedback также сочетает timing и spring.

В раскрытом плеере свайп обложки альбома по горизонтали переключает трек (влево — следующий, вправо — предыдущий):
- Жест обложки имеет пороги `activeOffsetX([-12, 12])` и `failOffsetY([-20, 20])`, делегируя вертикальный свайп родительскому `mainSwipeGesture`. В `createSwipeDownGesture` добавлен флаг `isClosingShared`, предотвращающий ложный отскок плеера обратно в раскрытое состояние при сворачивании.
- Анимация выполнена на пружинах WWDC23 (`damping: 28, stiffness: 220, mass: 0.8`) с передачей `velocityX` при отпускании и поддержкой `ReduceMotion.System`.
- При отсутствии следующего/предыдущего трека применяется сопротивление (rubber-banding `dx * 0.25`) с возвратом на место.
- При коммите свайпа старая обложка вылетает за край экрана с передачей `velocityX`, а новая обложка после обновления `currentTrack` въезжает с противоположной стороны на пружине WWDC23 (`damping: 28, stiffness: 220, mass: 0.8`), что исключает мигания и рассинхронизацию между асинхронным циклом рендера React и нативным потоком Reanimated. Обложки предварительно загружаются через `prefetchCover`.

В режиме текстов песен (`AppleLyricsView.js`, `AnimatedLyricLine.js`, `lyricDepth.js`):
- Полная синхронизация поведения с веб-версией: построчное движение по типу волны («как машины в пробке» / wave spring propagation).
- Активная строка реагирует мгновенно (`delay = 0`, `stiffness: 185, damping: 20, mass: 0.8`), строки снизу подтягиваются с задержками реакции трафика (130ms, 230ms, 310ms...), а строки сверху — с каскадной упругой задержкой (45ms, 100ms, 160ms...).
- Оптический фокус удерживает активную строку на 40% высоты экрана (`focalY = Math.max(160, height * 0.40)`).
- При ручном скролле жест Pan временно отключает волновую задержку (`delay: 0`, `stiffness: 260, damping: 28, mass: 0.55`) и возвращает полную чёткость всему списку. Через 3.0 секунды бездействия автоскролл возобновляется и плавно возвращает список к активной строке.
- Тап по строке мгновенно сбрасывает смещение и перематывает воспроизведение на тайминг строки.

Для будущих изменений проверять API установленной Reanimated: доступные способы настройки spring, initial velocity, единицы измерения, поведение при смене цели и reduced motion. Если жест меняет нормализованный progress, скорость пальца нельзя передавать как скорость progress без преобразования.

Shared values и worklets использовать для покадрового движения; React-состояние — для смысловых состояний интерфейса. При завершении и отмене жеста проверять, что отложенный callback не закрывает уже повторно открытый плеер.

## Тема и материалы

Эмбиент-фон в полном плеере (`components/fullplayer/AmbientBackground.js`) реализован по модели Apple Music: увеличенная обложка с мягким дыханием (scale 1.45 ↔ 1.65), два плавающих световых орба, аппаратный `BlurView` (`intensity={80..95}`, `tint="dark"`) и трёхточечный виньеточный градиент `expo-linear-gradient` для сохранения контраста текстов и контролов. Смена трека выполняет двухбуферный кроссфейд (650ms), а при паузе анимация плавно возвращается в состояние покоя (1200ms). При `!isPlayerVisible` анимации останавливаются. Цвет читается из `cover_color` трека либо асинхронно запрашивается с `/api/color/{id}` с отменой устаревших ответов.

Проверка плавности и материалов выполняется на устройстве. Jest и экспорт bundle полезны для технических ошибок, но не заменяют эту проверку.
