# Реализация дизайна — веб

Общие решения: [DESIGN.md](DESIGN.md). Сценарии аудио и API описаны в [WEB_CLIENT_ARCH.md](../WEB_CLIENT_ARCH.md); визуальное направление определяется общим дизайн-документом. Компоновку проверять по текущему `App.tsx`, поскольку старый архитектурный документ содержит исторические решения.

## Карта кода

Все пути ниже относительно `app/web/src/`.

| Задача | Где смотреть |
|---|---|
| Реально подключённые экраны и режимы плеера | `App.tsx` |

## Компоненты и стили

Используются React, TypeScript, CSS Modules, Framer Motion, Zustand и TanStack Query. Версии проверять в `app/web/package.json`.

Общие статические значения брать из `variables.css`, если подходящий токен существует. Динамические стили допустимы для цветов и движения. DTO и API-контракты проверять в существующих типах; удалённый word-level пайплайн не использовать как образец.

UI обращается к воспроизведению через существующие actions store; AudioEngine остаётся независимым от React. Для Zustand использовать селекторы со стабильным результатом; составные селекторы требуют подходящего сравнения. Серверные запросы согласовывать с существующим Query-кэшем.

## Движение и доступность

Motion spring использовать для пространственных переходов и жестов, CSS/timing — там, где они подходят задаче. CSS-токен `--ease-spring` является кривой Безье и не обеспечивает физическую модель пружины или перенос скорости жеста.

Проверять поддержку velocity и смены цели в установленной версии Motion. Предпочитать transform/opacity для дешёвого движения; blur, тени и другие эффекты оценивать по измерениям в целевом браузере.

Учитывать `prefers-reduced-motion`, клавиатуру, видимый фокус, семантические кнопки и возврат фокуса после закрытия модалок. Hover-эффекты применять только для устройств с подходящим указателем; основные действия доступны без hover.

## Тема и проверки

В текущих токенах есть тёплый акцент; его точные значения остаются в CSS. Новую общую палитру ещё предстоит выбрать. Динамический фон полного режима реализуется через AmbientBackground; при изменении проверить отсутствие обложки и быстрое переключение треков.

В `app/web/` доступны `npm run lint`, `npm run test`, `npm run build`. Для визуальных изменений дополнительно проверить целевые размеры окна, браузер, прерывание переходов и читаемость материалов. Успешная сборка не подтверждает плавность.
