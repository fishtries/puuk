## Исправление задержки альбомов

После пользовательского импорта обнаружен timeout spotDL save на альбомах (180 сек.
с повторными попытками). Одиночный smoke test не покрывал этот сценарий.

Добавлен spotify_metadata.py: список берётся из Spotify embed, затем до 4 параллельных
запросов track embed проверяют точные массивы исполнителей, explicit и длительность.
Большие списки на границе возможного обрезания (100+) отвергаются; угадывания имён
артистов из общей строки нет. Формат embed не является стабильным публичным API;
его изменение вызывает явную ошибку. Для альбомного этапа общий бюджет 90 секунд.
Прогресс метаданных передаётся родителю через атомарно обновляемый файл.

На сервере: MILITANTUM — 17 позиций за 3.6 сек.; MUSIC — 30 за 6.1 сек.
64 серверных теста проходят. Новый worker и downloader установлены атомарно,
бот перезапущен. Операции 1 и 2 возобновлены с обнулением попыток после остановки
старого обработчика. Проверено: операция 1 создала полный снимок MUSIC на 30 треков
и перешла к этапу обработки аудио; операция 2 ожидает в очереди.

## MUSIC: диагностика отсутствия кандидатов

Для POP OUT, CRUSH и K POP реальный поиск YouTube Music на сервере возвращает
другие записи/других исполнителей. MUSIC также отсутствует среди альбомов в ответе
get_artist официального канала Playboi Carti. Явная установка location=US/GB результата
не изменила. Из этого нельзя вывести точную причину (регион/доступность/ответ каталога).
Проверка официального POP OUT -V_GygtBQJo через серверный yt-dlp: Video unavailable.
get_watch_playlist возвращает метаданные видео, но не подтверждение explicit.
Это не основание объявлять найденное видео проверенной uncensored-записью.

Исправлены два собственных дефекта: несовпадающие исполнители проверяются до explicit,
а (with/feat/ft) в названии убирается только для имён из точных credits исходного трека.
Все исполнители всё равно должны присутствовать у кандидата. Удаление live/remix и
ослабление explicit не выполнялись. Отсутствие самой записи в поиске получает понятную
причину вместо перечня свойств посторонних результатов. Поиск использует название без
дублирования уже известных feature credits.

Обновлены source_selection.py и source_worker.py, без остановки активного импорта.
Каждый следующий дочерний процесс читает новые файлы. MUSIC автоматически не запущен
повторно: доступный подтверждённый источник для него по этой проверке не найден.

## SoundCloud: получение publisher metadata и проверка скачивания

Добавлен soundcloud_source.py — локальное расширение экземпляра yt-dlp, сохраняющее
publisher_metadata.explicit, artist и album_title. Установленные пакеты не патчатся.
Применяется при поиске и при повторной проверке перед скачиванием. Поиск до 10 позиций
получает метаданные extract_flat без предварительного получения аудиоформатов.
Кандидаты с недоступным аудио пропускаются; ограничения доступа/DRM не обходятся.

Объединённая строка publisher artist разрешается в исходный список credits только при
точном совпадении имён. Uploader не считается доказательством исполнителя. Для прямой
ссылки исправлен приоритет artist/track над uploader/title; бот сообщает, если источник
не подтверждает explicit. При автоматическом подборе unknown/false не заменяют true.

Серверные проверки:

  поэтому для исходного explicit Spotify-трека автоматически не принимается.

- 70 серверных тестов проходят, включая сохранение publisher fields в search/download,
  объединённые credits, запрет подмены explicit и запрет угадывания артиста по uploader.
- Развёрнуты soundcloud_source.py, source_worker.py, downloader.py и bot.py.
  Бот перезапущен, polling активен. Библиотека не изменялась тестовыми загрузками.

Для MUSIC доступный подтверждённый explicit-источник этим изменением не установлен.

## Упрощение по решению пользователя

Explicit больше не является обязательным фильтром: true даёт небольшой бонус ранга,
false/unknown не запрещают подходящий трек. Поля источника сохраняют фактическое значение.
Live/sped up/исполнители/длительность проверяются как раньше. При полном отказе бот
показывает «Не найдено», несколько названий и предложение прислать нужную версию ссылкой
YouTube/SoundCloud. При частичном успехе перечисляются только названия пропусков,
без технических причин. Убрана навязчивая оговорка explicit у прямых SoundCloud-ссылок.
82 локальных теста; обновлены bot/downloader/source_selection на сервере.
Этот раздел заменяет прежнее требование обязательного explicit=true.
