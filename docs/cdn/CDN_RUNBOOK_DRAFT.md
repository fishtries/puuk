## 8. Rollback and recovery controls

Stop conditions: any warm unauthorized audio, origin bypass/header append, JWT/secret leak, wrong bytes, retry loop, failed migration/readiness, severe RF regression or unexpected consumption. Freeze expansion and capture redacted case/config/build IDs. Existing downloaded bytes/open transfers cannot be revoked.

**Ordinary delivery rollback:** privileged backend operator sets issuance false, clears numeric pilot IDs, advances epoch, applies reviewed restricted config and restarts only puuk-brain with safe stop/drain verification. New tickets direct; client permission reuse drains within 30s plus one 3s ticket timeout. Foreground/session/server/epoch change clears remote permissions; reload web/app session for explicit local invalidation. Keep healthy playing CDN URL/origin/purge available through 1800s issued-permission drain; do not delete good local bytes solely to change delivery. Exposure bookkeeping/purge persists through `max_expires_at + 3600 + 30`; drained jobs are not labeled succeeded. Retain flags/consumer audit; no old DB restore.

**Security rollback:** ordinary off/epoch **plus** provider resource disable or signing-key invalidation; keep origin closed when relevant. Provider operation acceptance is not global revocation: allow up to documented propagation and observe denied warm probes at accessible PoPs, keeping incident open until verified and recording capability expiry. Purge alone or origin-secret rotation alone cannot revoke warm objects. Coordinate one historical/full purge only while safely disabled; wait observed operation completion before reopening; repeat the full negative matrix. Preserve DNS and certificates. If M1/M2 cannot execute incident closure, enabling CDN is blocked.

**Key rotation:** disable issuance/advance epoch first, no dual-key overlap assumption. Signing: matching server/edge new key via protected paths, observed cold/warm proof, then reopen only after review. Origin: temporarily close protected origin while updating backend/edge, prove cold equality/count/routing before reopen; cached valid capabilities may still work. Keep secret versions and rollback values only in protected custody. A rollback to a leaked key is forbidden; generate a clean matching pair instead. JWT unchanged.

**Code/build rollback:** disable CDN/share/origin as appropriate before restoring only manifest-owned predecessor files/assets/config. Pause old scanner/import/mutation jobs that cannot maintain registry/version state using reviewed ownership/control; direct read compatibility alone does not prove those writers safe. Retain additive schema and user data. Web restore previous assets first, previous index last; native use approved previous signed build/install path and record actual installed identity. Never claim instant downgrade on every user's iPhone. Reconcile identity/version state before re-enabling new writers/features.

**nginx/TLS/DNS rollback:** restore reviewed per-file config/symlink metadata and test before targeted nginx reload; retain deny-by-default isolated media boundary, never restore historical broad web origin as the delivery fallback. The operational fallback is authenticated direct playback through web. Restore only dedicated-origin DNS RRset/TTL if required and safe after drain; do not remove media/web records/validation or certificates to stop delivery. Certificate custody/renewal and loaded-config identity must be recorded by privileged operator; untested restore is a blocker, not a successful rollback.

**Partial failure/restart:** if hash/purge child or thread fails to stop/reap, do not report clean restart, release its ownership, overlap a new owner or fall back to pkill. Follow the accepted shutdown fencing/finite grace and escalate actual live ownership to operator; safe direct mode remains preferred. Preserve pending/failed exposure and operation IDs, sanitized reasons and durable limiter. Reconcile every published manifest path and observed operation before resuming. Ordinary code rollback never drops outbox/tombstones or silently resumes legacy unsafe writers.
