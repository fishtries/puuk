# Native Retry integration decision — 2026-11-16

Coordinator owns this implementation decision. The user confirmed there are no other workers and identified GitHub Actions as the native build route; the shared iOS write fence is lifted. No new workers were launched. Existing unrelated dislikes, artist-selector, recommendation and bot changes remain outside the commit.

The existing source identity API cannot atomically install a paused source while validating native intent. A JavaScript snapshot followed by an unguarded install is insufficient. Add `replaceWithExpectedIntent(source, attempt, revision, expectedAttempt, expectedIntent)` and capability `puukExpectedIntentVersion = 1`, preserving the existing identity version and methods. The operation holds the existing recursive source lock across validation and installation; it accepts only a matching nonnegative revision, source attempt (including nil), and play/pause intent, rejects released/invalid sources, and does not change intent or autoplay. Interrupted snapshots are rejected.

Retry captures native status before ticket resolution and supplies the snapshot to atomic installation. Terminal unload errors become observable and attempt a best-effort pause; they do not claim successful cancellation. Retry cleanup and subscriber notification cover invalid snapshots. Later native intent changes reject installation even if a source-less event cannot be attributed by JavaScript. Existing newer wake, intent generation and per-source timeout changes are retained.

Compatibility: capability is checked explicitly; the old guarded method remains usable for play intent. Paused Retry on an older binary stays in error without installing a source. This compatibility limitation requires a rebuilt binary for paused preparation and is not claimed as full old-binary support. No CDN or Share feature switch is enabled by this change.

This extends the S4 implementation allowlist to `scripts/patch-expo-audio.js` and its existing patch tests. The frozen G1 contract and hashes remain historical; this addendum records the resolved API implementation gap, not security acceptance. It does not close S4/G3: independent review of the final integrated change and a rebuilt physical-device run remain required before enablement. GitHub Actions builds an unsigned IPA on push; successful compilation/export alone is not installed-device evidence.
