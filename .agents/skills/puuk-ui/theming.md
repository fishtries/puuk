# Theming — динамический цвет под обложку

Как работает адаптивная тема Puuk и как её расширять.

## Два механизма

### 1. AmbientBackground — извлечение палитры из обложки

`src/components/player/AmbientBackground.tsx`:
- Анализирует пиксели обложки (`getCoverUrl`), извлекает доминирующие цвета.
- `rgbToHsl` — перевод в HSL для манипуляций светлотой/насыщенностью.
- Рисует амбиентные волны (6 WaveNode: базовые тёмные + accent-подсветка)
  поверх `--bg-app`.
- Результат: у каждого трека своя атмосфера без смены всей темы.

### 2. generateAccentColor — детерминированный фолбэк

`src/store/usePlayerStore.ts`:

```ts
function generateAccentColor(str: string): string {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    hash = str.charCodeAt(i) + ((hash << 5) - hash);
  }
  const h = Math.abs(hash % 360);
  return `hsl(${h}, 70%, 55%)`;
}
```

Хеш строки → hue. Стабильно между сессиями, не требует canvas. Фолбэк, когда
анализ обложки недоступен/не удался.

## Правила работы с акцентом

- Потребители всегда читают CSS-переменные (`var(--accent-color)`,
  `var(--accent-glow)`), а не «текущий цвет» из JS. Обновление переменной
  мгновенно перекрашивает всё дерево.
- Производные цвета считаются от акцента с фиксированной прозрачностью:
  `--accent-subtle: rgba(accent, 0.14)`, `--accent-glow: rgba(accent, 0.28)`.
- Контраст текста на акценте проверять ≥ 4.5:1 (WCAG AA). Светлоту акцента в
  HSL держать в диапазоне, дающем читаемый `--text-primary` поверх.
- Фолбэк обязателен: трек без обложки / офлайн → `generateAccentColor` + дефолтный
  индиго `#6366F1`.

## Что можно

- Добавлять новые производные переменные в `variables.css` (комментарий + группа).
- Усиливать depth-of-field эффекты (`--lyrics-blur`).
- Смягчать/десатуратировать извлечённые цвета, если «кричат».

## Что нельзя

- Хардкодить цвета обложки в компонентах.
- Перекрашивать нейтральные поверхности (`--bg-*`) под трек — акцент живёт
  только в акцентных токенах и амбиенте.
- Высокочастотные обновления переменных (на каждый `timeupdate`) — тема
  меняется при смене трека, не чаще.
- Анимировать сам цвет фона через `transition: background` на body — дорого;
  плавность делает AmbientBackground через свои волны.
