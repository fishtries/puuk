# Puuk UI

Общий дизайн веба и iOS: [DESIGN.md](../../../docs/design/DESIGN.md).

1. Прочитать относящийся к задаче раздел общего документа. Отличать принятые решения, текущую реализацию и открытые вопросы.
2. Читать справочник целевой платформы: [iOS](../../../docs/design/ios.md) или [веб](../../../docs/design/web.md). Для общей задачи читать оба.
3. Проверить указанные компоненты в текущем коде; использовать существующие обработчики, стили и значения.
4. Настраивать движение средствами установленной библиотеки. Параметры SwiftUI не копировать в Reanimated или Motion без проверки соответствия.
5. Проверять затронутые состояния и взаимодействия по разделу «Состояния и проверка». Сообщать о пределах визуальной проверки.

При обычном исправлении API или аудио-логики без изменений интерфейса этот skill не требуется. Общие дизайн-решения обновлять в `docs/design/`; технические значения хранить в коде платформы.
