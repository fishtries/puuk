# Refactoring Skill

Use this skill when a task involves behavior-preserving code improvement: restructuring existing modules, extracting responsibilities, removing duplication, or preparing code structure before adding new features.

**Do not use** for new feature implementation (that's not refactoring) or cosmetic style changes (renaming for convention, formatting).

Before making design or code decisions, read and apply [refactoring.mini.md](refactoring.mini.md). Use [refactoring.md](refactoring.md) only as a deeper reference when the mini rules are not enough for the current refactoring tradeoff.
